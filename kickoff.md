# Kickoff Prompts

Attach the room photo to a new ChatGPT chat, then paste one of these.

## Full

```text
Source of truth: https://raw.githubusercontent.com/kiianlow/interior-reimagine-workflow/main/START-HERE.md
Read it fully and follow it. If the raw link will not open, use https://github.com/kiianlow/interior-reimagine-workflow/blob/main/START-HERE.md

Room: [living room / master bedroom / common bedroom / kitchen / bathroom / dining / balcony / study]
Styles: [one or more numbers, for example 04 or 01, 02, 06]
Mode: [REVAMP / STAGE]
Property: [HDB / condo / EC / landed], [low / mid / high floor]
Also keep: [optional, for example existing kitchen cabinets]
Also change: [optional, for example remove window grilles]
Keep the architecture, dimensions and every fixed fixture exactly where they are.
```
